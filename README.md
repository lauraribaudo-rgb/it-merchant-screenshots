# it-merchant-screenshots

Public image host for the weekly IT merchant code/offer monitor
(see the private repo: https://github.com/lauraribaudo-rgb/it-merchant-code-monitor).

Contains only homepage screenshots of merchants' own public websites —
one dated folder per weekly run, e.g. `2026-08-20/farmacart.png`.
Images here are referenced via raw.githubusercontent.com links embedded
directly in the weekly report email, so it needs to stay public.
